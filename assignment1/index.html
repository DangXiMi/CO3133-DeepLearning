1. Problem Statement

Given a 28×28 grayscale image of a clothing item, predict one of ten Fashion-MNIST classes. The task is a controlled comparison of five architecture families under one data split and evaluation protocol: a linear/softmax classifier, an MLP, a self-designed CNN, a GRU, and a Transformer. The comparison uses accuracy, macro-F1, parameter count, training time, inference time, learning curves, confusion matrices, and qualitative examples — not accuracy alone.

2. Dataset and EDA

Dataset: Fashion-MNIST (Xiao et al., 2017), obtained through torchvision.datasets.FashionMNIST; MIT license. It contains 70,000 28×28 grayscale images in 10 classes, with the official 60,000/10,000 train/test split.

Split: the 60,000 training images were split with train_test_split(test_size=0.2, stratify=y, random_state=42), giving 48,000 train / 12,000 validation / 10,000 test images. The split is shared by every model. The dataset is balanced: 4,800 training, 1,200 validation, and 1,000 test images per class.

Preprocessing: images are converted to float, scaled to [0, 1], then z-scored with the training-set mean (0.2863) and standard deviation (0.3532). The same transform is applied to validation and test. No augmentation is used in the main comparison.

EDA: class distribution, pixel-value and non-zero-pixel distributions, near-black background statistics, and representative samples per class are in assignment1/eda.ipynb.

All models output raw logits and are trained with cross-entropy loss. The CNN is self-designed and trained from scratch; no pretrained backbone is used. The GRU and Transformer both read the image as 28 rows, so their difference isolates recurrence versus self-attention.

4. Experimental Setup

  • Optimizer: Adam, learning rate 1e-3.
  • Batch size: 64; epochs: 10 for every model.
  • Loss: CrossEntropyLoss on raw logits.
  • Gradient clipping: max norm 1.0 for all models.
  • Seed: 42 (Python, NumPy, PyTorch CPU/CUDA).
  • Checkpoint selection: best validation macro-F1; the selected checkpoint is evaluated on the 10,000-image test set.
  • Augmentation / scheduler / early stopping: none; fixed 10-epoch budget.
  • Hardware: NVIDIA GeForce RTX 3050 Laptop GPU (4 GB), CUDA 13.0.
  • Software: Python 3.14.7, PyTorch 2.14.0, torchvision 0.29.0.
  • Timing: training time covers 10 epochs including per-epoch validation and checkpointing; inference time is a full forward pass over the test set after warmup, excluding loss/metric computation.

Full configuration and per-epoch histories: config.json, results.csv, results.json.

6. Comparison and Discussion

The CNN is the strongest model on this protocol: 91.83% test accuracy and 91.78% macro-F1. It is 2.9 points above the GRU, 3.1 points above the Transformer, 3.9 points above the MLP, and 7.7 points above the linear classifier.

The result is consistent with inductive bias. Convolution shares weights across image positions and pools local neighborhoods, so it sees the 2-D structure of clothing silhouettes directly. The MLP and linear model flatten the image and lose locality. The GRU and Transformer read the image as 28 rows; they can model order along the vertical axis, but they do not have an explicit 2-D neighborhood operator. The GRU reaches 88.93% with only 61,962 parameters, showing that the row-sequence representation is still useful. The Transformer (69,450 parameters) is close behind at 88.71%. The manual GRU loop is the slowest to train (58.0 s) because each batch runs 28 single-step cells; the Transformer takes 36.7 s.

The parameter/accuracy trade-off is not monotonic. The MLP has 235,146 parameters but is below the 61,962-parameter GRU, so capacity alone does not explain performance. The CNN's advantage comes from the combination of local feature extraction and a sufficiently large classifier head.

7. Error Analysis

The dominant error group for every model is the upper-body clothing cluster: Shirt, T-shirt/top, Pullover, and Coat. These classes have similar silhouettes at 28×28 resolution, and grayscale removes color cues. The CNN reduces this confusion but does not eliminate it: its largest off-diagonal counts are Shirt → T-shirt/top (94), Shirt → Coat (84), T-shirt/top → Shirt (78), Shirt → Pullover (62), Pullover → Shirt (52), and Coat → Pullover (49). Shirt remains the hardest class for every model; its CNN F1 is 0.761, compared with 0.601 for the linear model.

The second group is footwear: Ankle boot ↔ Sneaker ↔ Sandal. The linear and MLP models confuse these more often because they have no local shape detector. The sequence models also confuse Shirt with T-shirt/top and Coat, which suggests that row order alone does not capture the 2-D outline of a garment.

Possible improvements: light augmentation (horizontal flips for shoes, small translations), a patch-token Transformer instead of row tokens, stronger regularization for the MLP/CNN heads, and a CNN + sequence hybrid. Because the dataset is balanced, class-weighted loss is not the main issue here.

8. Limitations and Conclusion

This comparison uses one dataset (Fashion-MNIST), one seed (42), a fixed 10-epoch budget, and no augmentation in the main pipeline. Hyperparameters were not extensively tuned, and the sequence models use row tokens rather than patch tokens. The reported differences should therefore be read as results under this controlled protocol, not as universal claims about the architecture families. A multi-seed mean ± standard deviation and a patch-token ablation would strengthen the conclusion.

Under the shared split and protocol, the self-designed CNN is the best model by both accuracy and macro-F1. The GRU is the best sequence model and is competitive with far fewer parameters; the Transformer is close but slower to train. The linear model and MLP establish the value of non-linear and spatial inductive bias.
